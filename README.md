# Mentalist

Привычки, фокус-таймер, аура, друзья и кланы. Обычный сайт (PWA): ставится на iPhone и Windows как приложение.

## 1. Сервер (Supabase, бесплатно)

1. Зарегистрируйтесь на https://supabase.com и нажмите **New project** (регион ближе к вам, пароль базы сохраните себе).
2. **SQL Editor → New query** → вставьте весь `schema.sql` → **Run**.
3. **Authentication → Sign In / Providers → Email**: выключите **Confirm email** и сохраните.
   Вход в приложении идёт по нику и PIN, настоящая почта не используется.
4. **Project Settings → API**: скопируйте **Project URL** и ключ **anon public** в `config.js`.

## 2. Проверка у себя

```
node serve.js
```
Откройте http://localhost:8097

## 3. Публикация (GitHub Pages)

Залить папку в отдельный репозиторий GitHub → **Settings → Pages → Deploy from branch → main / root**.
Сайт будет по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Установка на устройство

- **iPhone:** Safari → «Поделиться» → «На экран „Домой“».
- **Windows:** Edge или Chrome → значок установки в адресной строке.

## Аура

+10 за привычку (до 10 в день), +1 за минуту фокуса (до 240), +25 за идеальный день,
×1.2 при серии от 7 дней, ×1.5 от 30. Максимум 600 в день. Начисляется только за вчера и сегодня.
Ранги: Новичок 0 · Ученик 500 · Практик 2 000 · Мастер 6 000 · Ментор 15 000 · Менталист 40 000.
Лиги недели: Бронза · Серебро 700 · Золото 1 800 · Алмаз 3 200.
